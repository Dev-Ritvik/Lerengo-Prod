# LerenGO – Campus Network MVP
Version: 1.0
Timeline: 3 Weeks
Scope: Single University Launch

## 1. Problem

Students lack:
- Verified, structured academic notes
- Organized campus-specific digital space
- Reliable doubt resolution from trusted seniors

Existing solutions are unstructured (WhatsApp, Telegram).

Campus Network provides a university-isolated, verified academic platform.

---

## 2. Target User

Primary:
- Engineering students (1–3 year)
- Single university for MVP

Secondary:
- High CGPA seniors
- Admin team

---

## 3. Core Features (MVP Only)

1. Google Authentication
2. University selection & isolation
3. Admin-uploaded notes
4. Paid note unlock via Razorpay
5. Basic doubt posting (free for MVP)
6. Role system (user, senior, admin)

---

## 4. Non-Scope

- Mentorship marketplace
- Freelancing
- Hackathons
- Internship portal
- Wallet system
- Multi-university scaling

---

## 5. Success Metrics

- 100 verified users
- 30 paid note unlocks
- 0 cross-university leaks
- 0 payment unlock errors

---

## 6. Critical Rules

- Paid content unlock ONLY after webhook verification.
- University isolation enforced server-side.
- No secrets exposed in frontend.
